# System Revision List

## 1. Chat, Notifications, and Reports

- Improve chat controls and reporting features.
    
- Ensure consistency in confirmation messages and system notifications.
    
- Allow users to send photos and files through the chat.
    
- Add a profanity filter to automatically hide or censor inappropriate words.
    

## 2. Payment Terms

- Add support for flexible payment terms and payment arrangements.
    

## 3. CEO-to-Supplier Communication

- Provide a feature or communication channel for direct CEO-to-supplier coordination, if applicable.
    

## 4. Autofill Functionality

- Add autofill functionality to reduce repetitive data entry in forms.
    

## 5. Supplier Registration and Account Management

- Improve the supplier registration process for both B2B and B2C transactions.
    
- Instead of requiring suppliers to register themselves, the Procurement Team should be able to create the supplier account directly.
    
- If a separate supplier portal is retained, the system should include proof or documentation that GCE officially invited or instructed the supplier to register.
    
- After registration, the supplier must wait for GCE's approval before being allowed to log in.
    
- Suppliers must indicate whether they are registering as a **Company** or an **Individual**.
    
- Clearly list the accepted valid IDs that suppliers must present to GCE.
    
- Require **two primary valid IDs** for verification.
    

## 6. UI and Text Visibility

- Improve font and text visibility against the background.
    
- Pay special attention to readability in **Light Mode**, where some text currently has insufficient contrast.
    

## 7. Mobile Application Download

- Allow users to download the mobile application directly from the system.
    
- Remove unnecessary redirects or visits to external websites whenever possible.
    

## 8. Form Data Validation

- Add proper validation to all form fields.
    
- Define restrictions such as:
    
    - Maximum and minimum numbers
        
    - Maximum text length
        
    - Allowed data types
        
    - Required fields
        
    - Valid formats for specific inputs
        

## 9. Car Listing Improvements

Add the following information to car listings:

- Warranty details
    
- Promotional or sale offers
    
- Vehicle condition
    
- Pricing type
    

For pricing, provide checkboxes or options for:

- **Negotiable Price**
    
- **Fixed Price**
    

## 10. Vehicle Document Checklist

- Add a checklist of required vehicle documents to ensure that all necessary documents are submitted and verified.
    

## 11. Mechanic Inspection Checklist

- Organize the mechanic's checklist using a **hierarchical structure** based on vehicle systems, components, and parts.
    

Example structure:

- Engine
    
    - Oil System
        
    - Cooling System
        
    - Belts
        
- Brakes
    
    - Brake Pads
        
    - Brake Discs
        
- Suspension
    
    - Shock Absorbers
        
    - Bushings
        

## 12. Parts Repair and Replacement

- If a mechanic marks a part as requiring repair or replacement, additional fields should automatically appear.
    
- The mechanic should provide:
    
    - Replacement part or item name
        
    - Brand
        
    - Estimated cost
        

## 13. Inspection Report

- Simplify the inspection report to avoid redundant data entry.
    
- Each inspected component should only require the mechanic to select one of the following statuses:
    
    - **Good**
        
    - **For Repair**
        
    - **For Replacement**
        
- The inspection report should automatically fetch the information already entered in the mechanic's checklist instead of requiring the same data to be entered again.
    

## 14. Submission, Approval, and Deletion Confirmation

- Add confirmation prompts for important actions involving submissions, approvals, and deletions.
    
- Examples:
    
    - “Are you sure you want to submit this?”
        
    - “Are you sure you want to approve this?”
        
    - “Are you sure you want to delete this?”
        
- Apply these confirmation indicators consistently across all relevant modules.
