# Objective
## Roadmap Page Redesign Using Template Dashboard Components

---

## Role
You are a frontend UI/UX developer specializing in component-based design systems and template-driven development. Approach this objective with a focus on design fidelity, exact component replication, and data integration without visual deviation.

---

## Description
The objective is to redesign and enhance the Roadmap page located at http://localhost:3000/{user}/roadmap by incorporating exact component designs from two reference template dashboards. From the Academy template dashboard, the Performance Highlights cards, Upcoming Events card, and Class Schedule card must be replicated with complete design fidelity — no customization, modification, or styling changes are permitted beyond integrating real database data. From the Productivity template dashboard, the Projects section containing roadmap and project cards such as Q2 Roadmap and Website Redesign must be replicated with the same strict fidelity. All components must display live data from the database while preserving their original template designs exactly.

## Detailed Breakdown

### Design Fidelity Requirement
Every component sourced from the Academy and Productivity template dashboards must be replicated with absolute fidelity. This means no changes to CSS classes, inline styles, spacing values, typography, color schemes, border radii, shadows, hover states, responsive breakpoints, or any other visual or structural property. The only permitted difference between the template components and their Roadmap page counterparts is the data content, which must be sourced from the live database.

### Data Integration Approach
For each component, identify the data shape and properties the template component expects to receive. Map these to the corresponding database tables, fields, or API endpoints that supply the Roadmap page's real data. Transform or alias database field names as necessary to match the component's expected props or data structure. Under no circumstances should the component's internal rendering logic, markup, or styling be modified to accommodate data differences — all adaptation must occur at the data integration layer.
