# Objective: Implement GCE Client Change Requests

## Role

Full-stack web developer working on the Global Car Exchange (GCE) system's customer portal, staff portals, role-based access control, and third-party API integrations.

## Goal

Implement every addition, change, fix, and removal the client and Technical Adviser requested, across the customer side and each staff role.

- Replace placeholder dashboard data with accurate system data.
- Remove redundant or unused UI elements.
- Add verification APIs for submitted OR/CRs and IDs.
- Restructure RBAC so that the CEO holds full access.

## Success Criteria

- Every item in the Tasks section below (G1–D1) is implemented and checked off.
- All staff dashboards show real system data instead of template values (e.g., $1,250.00 Total Revenue, 1,234 New Customers, 45,678 Active Accounts, 4.5% Growth Rate).
- The reported broken features work: clickable notifications, file and image sending in My Inquiries, Create a Walk-in, and Payroll "Create Run".

## Constraints

- PHP is the only currency. Remove all other currency and balance options.
- Brand and Model dropdowns must still allow free typing.
- Budget-based car recommendations are a recommendation list only.
- Finance tables show a maximum of 10 rows per page, with Next/Previous pagination.
- The Account Manager can configure settings for other employees but must not be able to grant RBAC access.
- Field Cases must be removed from the Account Manager role, which is not authorized for them.

## Context

- Source: the client's "Recommend ni TechAd" document (Oct 26, 2026), which contains requests from the client and the Technical Adviser.
- Roles: Customer, Sales Manager, Head Accountant, Account Manager, Marketing Specialist, Confidential Informant (CI), and the new CEO role.
- Currently, the Account Manager is given RBAC access automatically when the account is created.
- Required third-party APIs:
  - OR/CR verification (Customer → Sell a Car)
  - ID verification (Sales Manager → Transactions)
  - Geolocation (Deliveries)
- Reference for the pagination layout: the existing "Pending Price Approvals" table (Rows per page: 10 · Page 1 of N).
