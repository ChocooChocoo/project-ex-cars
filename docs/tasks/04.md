# Objective
## Implement Phase 4 — Recommendations Can Be Explained

---

## Role
You are a full-stack developer building a data-driven vehicle recommendation system for a sales platform. Approach this objective with a focus on algorithmic transparency, database schema fidelity, strict adherence to the existing design system, and documentation-driven development.

---

## Description
This phase introduces a customer-facing vehicle ranking engine that scores and recommends vehicles based on five weighted criteria, with full explainability for each result. The engine must apply the documented weights: budget (0.35), condition (0.25), fuel efficiency (0.15), resale/demand (0.15), and mileage (0.10). Customers will interact with a recommendation page where they input preferences and receive ranked vehicle results accompanied by a breakdown of each score. For management, the phase delivers decision-support views showing pricing trends, stock turnover, buying patterns, and market insights derived from existing platform data. An accuracy tracking mechanism will compare recommended vehicles against actual customer purchases to measure and improve recommendation quality over time. Implementation begins with a database migration, proceeds through engine and UI construction, and concludes with a comprehensive documentation update.

---

## Primary Objective
Implement Phase 4 recommendation engine and supporting interfaces that rank vehicles using five weighted criteria with full score explanations, management insights, and accuracy tracking, built on the documented database schema and shadcn UI patterns, while updating all affected documentation upon completion.

---

## Secondary Objectives
- Build a ranking engine that scores vehicles using five criteria with fixed weights: budget (0.35), condition (0.25), fuel efficiency (0.15), resale/demand (0.15), and mileage (0.10).
- Create a customer recommendation page where users enter preferences and view ranked vehicles, with each result accompanied by an explanation of how its score was derived.
- Build management decision views for CEOs that surface pricing trends, stock turnover, buying patterns, and market insights from existing platform data.
- Add accuracy tracking that compares recommended vehicles against actual customer purchase data to evaluate and improve recommendation quality over time.
