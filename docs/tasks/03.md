## What to Build

**R-09 — Vehicle-linked Inquiry Chat**
- Customers start an Inquiry or Buy Now from any vehicle detail page
- Real-time chat tied to the vehicle (use Supabase Realtime)
- Messages carry text + optional images/files

**R-10 — Inquiry Routing & Scheduling**
- Inquiry → Account Manager queue; Buy Now → Sales Manager queue
- Staff assign themselves to conversations
- Auto-fill arrangement forms from stored profile data
- Delivery / CALABARZON meet-up / GCE visit scheduling
- Account Manager → Sales Manager handoff for GCE visits

**R-11 — Unread Counts & Read State**
- Unread message badge per conversation
- Mark messages read when viewed

**R-35 — Attachments & Reporting**
- Upload photographs/files inside chat (bucket: `chat-attachments`)
- Report a message or conversation for review

**R-36 — Word Filter**
- Automatic hide or censor of inappropriate words on message display
