# Objective
## Suppliers Page Table Redesign and Detail Drawer UI/UX Enhancement

---

## Role
You are a frontend UI/UX developer specializing in template-driven component reuse and information hierarchy design. Approach this objective with a focus on exact table replication, subtle visual hierarchy improvements, and form usability enhancements.

---

## Description
The objective is to redesign the Suppliers page located at http://localhost:3000/ceo/suppliers by replacing the existing table with the exact customers table design from the Default template dashboard. The template table must be replicated with complete fidelity, preserving the search box, filter dropdowns, pagination controls, table layout, styling, and all columns without modification — only the data content and the Action column's context menu items may be adapted. Additionally, the view details drawer requires UI/UX improvements including better visual hierarchy, enhanced form design, and overall polish without over-redesigning or introducing excessive changes.

---

## Primary Objective
Redesign the Suppliers page table by faithfully replicating the customers table from the Default template dashboard, and improve the UI/UX of the view details drawer with better hierarchy and form design while avoiding over-redesign.

---

## Secondary Objectives
- Replicate the customers table from http://localhost:3000/template/dashboard/default with exact design fidelity — preserving search box, filter dropdowns, pagination controls, table layout, styling, and all columns — as the replacement table on the Suppliers page.
- Adapt only the table's data bindings and the Action column's context menu items to match the Suppliers context, while keeping the three-dots icon (⋮) trigger.
- Improve the visual hierarchy of the view details drawer so information is better organized and easier to scan.
- Enhance form elements within the view details drawer for improved usability and visual consistency.

---

## Success Criteria
- The Suppliers page table is visually and structurally identical to the Default template dashboard's customers table, differing only in data content and Action menu items.
- The search box, filter dropdowns, pagination controls, and overall table structure remain unmodified from the template.
- The Action column retains the three-dots icon (⋮) that opens a context menu with supplier-relevant actions.
- The view details drawer exhibits clear visual hierarchy, with information grouped and prioritized logically.
- Form elements within the drawer are improved in usability and visual consistency without excessive redesign.
- Both the table and drawer are fully integrated into the Suppliers page at http://localhost:3000/ceo/suppliers.

---

## Constraints
- The customers table from the Default template must not be redesigned or modified in any way beyond data content and Action menu items.
- The view details drawer improvements must not constitute an over-redesign — changes should be restrained and purposeful.
- All tasks must be executed using multiple agents and skills from the .opencode folder.

## Detailed Breakdown

### Table Design Fidelity Requirement
The customers table from the Default template dashboard must be replicated with absolute fidelity. This includes the search box with its exact placeholder text, input styling, and search behavior; all filter dropdowns with their options, styling, and interaction patterns; pagination controls with their exact layout, button styling, and page size options; the table layout including column widths, alignment, header styling, and row treatments; and all visual styling including borders, spacing, typography, hover states, and alternating row colors if present. The only permitted deviations are the data content populating the rows and the actions available in the Action column's context menu. The three-dots icon (⋮) that triggers the context menu must remain unchanged.

### Drawer Enhancement Guidelines
Enhancements to the view details drawer must be restrained and purposeful. Visual hierarchy improvements may include adding clear section headings, grouping related fields into logical clusters, establishing consistent spacing between groups, and using subtle visual separators where appropriate. Form enhancements may include normalizing input widths, improving label alignment, ensuring consistent spacing between form fields, and applying a cohesive visual treatment to all interactive elements. The goal is a polished, professional drawer that is easier to scan and interact with, without introducing dramatic visual changes or unnecessary decorative elements.
